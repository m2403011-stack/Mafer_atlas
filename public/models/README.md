# Modelo anatómico local opcional

La aplicación intenta cargar primero `public/models/body.glb`.

Si el archivo no existe, utiliza como respaldo un modelo web derivado de Z-Anatomy alojado públicamente. Para tener funcionamiento completamente local/offline, coloca aquí un archivo `body.glb` compatible y conserva las atribuciones y licencias del modelo que utilices.

Fuente sugerida para el MVP:
- Z-Anatomy / BodyParts3D, CC BY-SA 4.0.
- Revisa `THIRD_PARTY_NOTICES.md` antes de redistribuir cualquier modelo.
